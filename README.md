# MindGuard-Pro

A multimodal mental health risk assessment system using text, facial, and behavioral analysis.

## 📌 About the Project

MindGuard-Pro is a web-based multimodal mental health risk assessment system developed as an academic project.

The system analyzes multiple types of information during a screening session, including:

- Text-based responses
- Facial information
- Behavioral indicators

The different modalities are combined to generate an overall risk assessment.

> **Disclaimer:** This project is developed for academic and research purposes. It is not a medical diagnostic tool and should not replace professional mental-health care.

## ✨ Features

- Text-based mental health risk analysis
- AI-assisted conversational screening
- YOLOv8-based facial detection
- Behavioral analysis
- Multimodal result combination
- Risk assessment generation
- Results and performance visualizations
- FastAPI backend
- Interactive HTML/CSS/JavaScript frontend
